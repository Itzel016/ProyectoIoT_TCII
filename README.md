# Sistema IoT para el monitoreo de incendios en el interior de una vivienda.
El presente proyecto tiene cómo objetivo implementar tecnologías IoT para la creación de un prototipo funcional capaz de monitorear las variables ambientales dentro de un espacio interior y detectar de manera oportuna un posible incendio. Para ello el sistema cuenta con uso de sensores para identificar variables como temperatura, humo, gases y detección de fuego en el momento.
Los datos son procesados por medio de un microcontrolador que está conectado a internet, por el cual cuando detecte la presencia de flama dentro del entorno de monitoreo se realiza el envío de una notificación hacia el dispositivo del usuario que gestiona el sistema detector de manera anticipada para que el usuario pueda actuar oportunamente.
